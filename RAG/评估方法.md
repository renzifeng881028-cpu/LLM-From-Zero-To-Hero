# Ragas
### RAGAS（Retrieval Augmented Generation Assessment Suite）是目前评估 RAG 系统最流行的开源框架之一，专门用于评估 检索质量 + 生成质量，而不仅仅是看最终答案对不对。

#### Faithfulness（忠实度）
- 答案是否完全来源于检索内容。
#### Answer Relevancy（答案相关性）
- 回答是否真的在回答问题。
#### Context Precision（上下文精准率）
- 检索出来的内容有多少是真正相关的。
#### Context Recall（上下文召回率）
- 检索内容是否包含回答问题所需的全部信息。
